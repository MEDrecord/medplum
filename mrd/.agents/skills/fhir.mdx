# FHIR Skills

Domain knowledge for working with FHIR resources in the MEDrecord platform.

## Resource Mapping

### Templates → PlanDefinition

Templates (both note templates and questionnaires) are stored as `PlanDefinition` resources.

```typescript
// Template types
type: 'note-template' → action.definitionUri contains sections
type: 'questionnaire' → action[0].definitionCanonical references Questionnaire
```

### Questionnaires → Questionnaire

Questionnaire forms are standard FHIR `Questionnaire` resources with MEDrecord extensions.

### Questionnaire Tasks → Task

When a questionnaire is assigned to a patient:

```typescript
Task {
  status: 'requested' | 'in-progress' | 'completed' | 'cancelled',
  focus: { reference: 'Questionnaire/xxx' },
  for: { reference: 'Patient/xxx' },
  encounter: { reference: 'Encounter/xxx' },
  code: {
    coding: [{ system: 'medrecord', code: 'questionnaire-task' }]
  }
}
```

### Questionnaire Responses → QuestionnaireResponse

```typescript
QuestionnaireResponse {
  questionnaire: 'Questionnaire/xxx',
  status: 'completed',
  subject: { reference: 'Patient/xxx' },
  encounter: { reference: 'Encounter/xxx' },
  item: [
    { linkId: 'q1', answer: [{ valueInteger: 2 }] }
  ]
}
```

### Scores → Observation

Calculated scores from questionnaires:

```typescript
Observation {
  status: 'final',
  code: {
    coding: [{ system: 'http://loinc.org', code: '44261-6' }]  // PHQ-9 score
  },
  subject: { reference: 'Patient/xxx' },
  derivedFrom: [{ reference: 'QuestionnaireResponse/xxx' }],
  valueInteger: 15,
  interpretation: [{
    coding: [{ system: 'medrecord', code: 'moderate' }]
  }]
}
```

## Common Operations

### Create Template

```typescript
const template = await medplum.createResource({
  resourceType: 'PlanDefinition',
  title: 'PHQ-9',
  status: 'draft',
  type: {
    coding: [{ system: 'medrecord', code: 'questionnaire' }]
  },
  action: [{
    definitionCanonical: 'Questionnaire/phq9'
  }]
});
```

### Search Templates

```typescript
const templates = await medplum.searchResources('PlanDefinition', {
  'type': 'questionnaire',
  'status': 'active',
  '_count': 20,
  '_sort': '-_lastUpdated'
});
```

### Create Questionnaire Task

```typescript
const task = await medplum.createResource({
  resourceType: 'Task',
  status: 'requested',
  intent: 'order',
  focus: { reference: `Questionnaire/${questionnaireId}` },
  for: { reference: `Patient/${patientId}` },
  encounter: { reference: `Encounter/${encounterId}` },
  code: {
    coding: [{ system: 'medrecord', code: 'questionnaire-task' }]
  }
});
```

### Submit Questionnaire Response

```typescript
const response = await medplum.createResource({
  resourceType: 'QuestionnaireResponse',
  questionnaire: `Questionnaire/${questionnaireId}`,
  status: 'completed',
  subject: { reference: `Patient/${patientId}` },
  encounter: { reference: `Encounter/${encounterId}` },
  authored: new Date().toISOString(),
  item: answers
});
```

### Update Task Status

```typescript
await medplum.updateResource({
  ...task,
  status: 'completed',
  output: [{
    type: { text: 'QuestionnaireResponse' },
    valueReference: { reference: `QuestionnaireResponse/${responseId}` }
  }]
});
```

## EnableWhen Logic

```typescript
import { isQuestionEnabled } from '@medplum/core';

// Check if question should be shown
const enabled = isQuestionEnabled(item, response);

// Example enableWhen
{
  linkId: 'phq9-10',
  text: 'If you checked off any problems...',
  enableWhen: [{
    question: 'phq9-total',
    operator: '>',
    answerInteger: 0
  }]
}
```

## Calculated Expressions

```typescript
import { evaluateCalculatedExpressionsInPlace } from '@medplum/core';

// Process calculated fields after each answer
evaluateCalculatedExpressionsInPlace(questionnaire, response);

// Example: calculated total score
{
  linkId: 'phq9-total',
  type: 'integer',
  readOnly: true,
  extension: [{
    url: 'http://hl7.org/fhir/uv/sdc/StructureDefinition/sdc-questionnaire-calculatedExpression',
    valueExpression: {
      language: 'text/fhirpath',
      expression: "item.where(linkId.startsWith('phq9-') and linkId != 'phq9-total').answer.value.sum()"
    }
  }]
}
```

## FHIRPath Expressions

Common patterns used in calculated expressions:

```fhirpath
// Sum all scores
item.where(linkId.startsWith('phq9-')).answer.value.sum()

// Count answered questions
item.where(answer.exists()).count()

// Get specific answer
item.where(linkId = 'q1').answer.value

// Conditional display
item.where(linkId = 'q1').answer.value > 2
```

## MedPlum Client Usage

### Server-Side Only

The MedPlum client is only used in the Gateway:

```typescript
// gateway/lib/medplum.ts
import { MedplumClient } from '@medplum/core';

let client: MedplumClient | null = null;

export function getMedplumClient(): MedplumClient {
  if (!client) {
    client = new MedplumClient({
      baseUrl: process.env.MEDPLUM_BASE_URL!,
      clientId: process.env.MEDPLUM_CLIENT_ID!,
      clientSecret: process.env.MEDPLUM_CLIENT_SECRET!,
    });
  }
  return client;
}
```

### Multi-Tenant Projects

```typescript
// Set project context for multi-tenant
const medplum = getMedplumClient();
medplum.setProject(tenantId);

// All subsequent operations scoped to tenant
const patients = await medplum.searchResources('Patient');
```
