# Gateway Service Specification

The Gateway is the central API service that all brand apps communicate with. It handles authentication, authorization, and proxies requests to MedPlum and other backend services.

## Service Overview

| Property | Value |
|----------|-------|
| Location | `mrd/gateway/` |
| Framework | Next.js 16 (App Router) |
| Deployment | Vercel |
| Domain | `gateway.medrecord.nl` (production) |

### Request Authentication

Every API request (except auth routes) requires a valid session:

```typescript
// lib/middleware/auth-middleware.ts
import { verifySession } from '../auth';

export async function authMiddleware(request: Request): Promise<AuthContext> {
  const sessionCookie = request.cookies.get('session');
  
  if (!sessionCookie) {
    throw new AuthError('No session', 401);
  }
  
  const session = await verifySession(sessionCookie.value);
  
  return {
    userId: session.userId,
    tenantId: session.tenantId,
    brand: session.brand,
    roles: session.roles,
  };
}
```

### Headers

| Header | Required | Description |
|--------|----------|-------------|
| `Cookie: session=xxx` | Yes | Session token (HTTP-only cookie) |
| `X-Brand` | Yes | Brand identifier (`healthtalk`, `coachi`, etc.) |
| `X-Tenant-Id` | No | Override tenant (admin only) |

## API Routes

### Templates

#### List Templates

```
GET /api/templates?type={type}&status={status}&page={page}&limit={limit}
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `type` | `note-template` \| `questionnaire` | Filter by template type |
| `status` | `draft` \| `published` | Filter by status |
| `page` | number | Page number (default: 1) |
| `limit` | number | Items per page (default: 20) |

**Response:**

```typescript
interface TemplateListResponse {
  templates: TemplateSummary[];
  pagination: {
    page: number;
    limit: number;
    total: number;
    totalPages: number;
  };
}
```

#### Create Template

```
POST /api/templates
Content-Type: application/json

{
  "title": "PHQ-9 Depression Screening",
  "type": "questionnaire",
  "language": "nl",
  "category": "mental-health"
}
```

#### Get Template

```
GET /api/templates/{id}
```

**Response:**

```typescript
interface TemplateDetailResponse {
  id: string;
  title: string;
  type: 'note-template' | 'questionnaire';
  status: 'draft' | 'published';
  language: string;
  category: string;
  version: number;
  createdAt: string;
  updatedAt: string;
  
  // Type-specific content
  sections?: Section[];           // For note-template
  questionnaire?: Questionnaire;  // For questionnaire
  scoringConfig?: ScoringConfig;  // For questionnaire with scoring
}
```

### Questionnaires

#### Submit Response

```
POST /api/questionnaires/{id}/responses
Content-Type: application/json

{
  "subject": { "reference": "Patient/123" },
  "encounter": { "reference": "Encounter/456" },
  "item": [
    {
      "linkId": "phq9-1",
      "answer": [{ "valueInteger": 2 }]
    }
  ]
}
```

This creates a `QuestionnaireResponse` in MedPlum, which triggers:
1. Scoring Bot (if scoring enabled)
2. Task status update

### Notifications

#### Send Questionnaire

```
POST /api/notify
Content-Type: application/json

{
  "taskId": "Task/789",
  "channel": "auto"
}
```

| Channel | Description |
|---------|-------------|
| `auto` | Gateway selects best channel based on patient contact info |
| `whatsapp` | WhatsApp interactive |
| `sms` | SMS with magic link |
| `email` | Email with magic link |
| `voice` | Voice agent call |

### AI Generation

#### Generate Report Section

```
POST /api/ai/generate
Content-Type: application/json

{
  "templateId": "Template/123",
  "sectionId": "subjective",
  "context": {
    "transcript": "...",
    "patientId": "Patient/456"
  }
}
```

This proxies to the own GPU AI service. No AI credentials exist in brand apps.

## Server-Side MedPlum Client

```typescript
// lib/medplum.ts
import { MedplumClient } from '@medplum/core';

let client: MedplumClient | null = null;

export function getMedplumClient(): MedplumClient {
  if (!client) {
    client = new MedplumClient({
      baseUrl: process.env.MEDPLUM_BASE_URL,
      clientId: process.env.MEDPLUM_CLIENT_ID,
      clientSecret: process.env.MEDPLUM_CLIENT_SECRET,
    });
  }
  return client;
}

// Usage in route handlers
export async function GET(request: Request) {
  const auth = await authMiddleware(request);
  const medplum = getMedplumClient();
  
  // Set project context for multi-tenant
  medplum.setProject(auth.tenantId);
  
  const templates = await medplum.searchResources('PlanDefinition', {
    _count: 20,
  });
  
  return Response.json({ templates });
}
```
