# Package Structure

The MEDrecord platform uses a monorepo structure with shared packages and brand-specific applications.

## Directory Structure

```
medplum/                              # Root (Medplum fork)
├── packages/                         # Upstream Medplum packages
│   ├── fhirtypes/                    # FHIR R4 TypeScript types
│   ├── core/                         # Core utilities, MedplumClient
│   ├── react-hooks/                  # React hooks (selective use)
│   └── ...                           # Other Medplum packages
│
└── mrd/                              # MEDrecord additions
    ├── .agents/                      # Platform agent configuration
    │   ├── config.yaml
    │   ├── instincts/
    │   ├── patterns/
    │   ├── skills/
    │   ├── specs/
    │   └── standards/
    │
    ├── packages/                     # Shared packages
    │   ├── shared/                   # @mrd/shared
    │   ├── sdk/                      # @mrd/sdk
    │   └── ui/                       # @mrd/ui
    │
    ├── gateway/                      # Gateway service
    │
    └── apps/                         # Brand applications
        ├── healthtalk/
        ├── coachi/
        ├── medsafe/
        └── medrecord/
```

## Packages

### @mrd/shared

Shared types, constants, and brand configuration. No React dependencies.

```
mrd/packages/shared/
├── src/
│   ├── index.ts
│   ├── brands/
│   │   ├── index.ts
│   │   ├── config.ts              # Brand configuration type
│   │   ├── healthtalk.ts          # HealthTalk brand config
│   │   ├── coachi.ts              # Coachi brand config
│   │   └── medsafe.ts             # MedSafe brand config
│   ├── types/
│   │   ├── index.ts
│   │   ├── template.ts            # Template types
│   │   ├── questionnaire.ts       # Questionnaire types
│   │   ├── appointment.ts         # Appointment types
│   │   ├── patient.ts             # Patient types
│   │   └── gateway.ts             # Gateway API types
│   └── constants/
│       ├── index.ts
│       ├── channels.ts            # Notification channels
│       └── locales.ts             # Supported locales
├── package.json
└── tsconfig.json
```

**package.json:**

```json
{
  "name": "@mrd/shared",
  "version": "1.0.0",
  "main": "src/index.ts",
  "types": "src/index.ts",
  "dependencies": {
    "@medplum/fhirtypes": "workspace:*"
  }
}
```

### @mrd/sdk

```
mrd/packages/sdk/
├── src/
│   ├── index.ts
│   ├── client/
│   │   ├── index.ts
│   │   ├── gateway-client.ts      # HTTP client for Gateway
│   │   ├── errors.ts              # Error types
│   │   └── types.ts               # Client types
│   ├── hooks/
│   │   ├── index.ts
│   │   ├── use-gateway.tsx        # GatewayProvider + useGateway
│   │   ├── use-auth.ts            # Authentication hooks
│   │   ├── use-templates.ts       # Template CRUD hooks
│   │   ├── use-questionnaire-form.ts  # Questionnaire form state
│   │   ├── use-appointments.ts    # Appointment hooks
│   │   └── use-notifications.ts   # Notification hooks
│   └── utils/
│       ├── index.ts
│       ├── fhir-helpers.ts        # FHIR utility wrappers
│       └── patient-language.ts    # Patient language extensions
├── package.json
└── tsconfig.json
```

**package.json:**

```json
{
  "name": "@mrd/sdk",
  "version": "1.0.0",
  "main": "src/index.ts",
  "types": "src/index.ts",
  "dependencies": {
    "@mrd/shared": "workspace:*",
    "@medplum/fhirtypes": "workspace:*",
    "@medplum/core": "workspace:*",
    "swr": "^2.2.0"
  },
  "peerDependencies": {
    "react": "^19.0.0"
  }
}
```

```json

  "main": "src/index.ts",

    "@mrd/sdk": "workspace:*"

    "next": "^16.0.0"

```

## What to Use from Medplum

| Package | Use | Purpose |
|---------|-----|---------|
| `@medplum/fhirtypes` | Yes | All FHIR R4 TypeScript types |
| `@medplum/core` | Selective | FHIRPath, validation, type guards, calculated expressions |
| `@medplum/react-hooks` | No | Too coupled to MedplumClient |
| `@medplum/react` | No | Mantine UI components |

### What to Import from @medplum/core

```typescript
// GOOD - Import these utilities
import {
  evalFhirPath,
  evalFhirPathTyped,
  isChoiceQuestion,
  isQuestionEnabled,
  getQuestionnaireAnswers,
  evaluateCalculatedExpressionsInPlace,
} from '@medplum/core';

// BAD - Don't import these (we have our own)
import { MedplumClient } from '@medplum/core';  // Use GatewayClient instead
```

## Workspace Configuration

**Root package.json:**

```json
{
  "name": "medplum-mrd",
  "private": true,
  "workspaces": [
    "packages/*",
    "mrd/packages/*",
    "mrd/gateway",
    "mrd/apps/*"
  ]
}
```

**pnpm-workspace.yaml:**

```yaml
packages:
  - 'packages/*'
  - 'mrd/packages/*'
  - 'mrd/gateway'
  - 'mrd/apps/*'
```
