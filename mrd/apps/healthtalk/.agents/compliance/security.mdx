# Security & Compliance

## 1. Non-Negotiable Security Rules

### 1.1 Data Flow

```
Frontend → API Route → Gateway → Database
```

**NOOIT** direct van frontend naar database.

### 1.2 Server-Side Only

De volgende operaties mogen **ALLEEN** server-side:

- Database access
- OpenAI/AI model calls
- Secret/credential access
- External API calls met credentials
- LOINC API calls

### 1.3 Auth Verificatie

Elk request moet geverifieerd worden met `auth.id` via gateway:

```typescript
export async function GET(request: Request) {
  // EERSTE stap - altijd auth verificatie
  const auth = await verifyGatewayAuth(request);
  
  // Pas daarna business logic
}
```

## 2. Credential Handling

### 2.1 Environment Variables

| Variable | Server-Only | Beschrijving |
|----------|-------------|--------------|
| `MEDPLUM_CLIENT_SECRET` | Yes | OAuth secret |
| `LOINC_PASSWORD` | Yes | LOINC API auth |
| `OPENAI_API_KEY` | Yes | AI model access |
| `NEXT_PUBLIC_*` | No | Client-safe config |

### 2.2 Credential Forwarding

**NOOIT** credentials forwarden naar client:

```typescript
// FOUT - credentials in response
return NextResponse.json({ 
  data, 
  apiKey: process.env.SECRET  // NOOIT DOEN
});

// GOED - alleen data
return NextResponse.json({ data });
```

## 3. CSRF Protection

### 3.1 Token Verificatie

```typescript
if (method !== 'GET') {
  const csrfToken = request.headers.get('X-CSRF-Token');
  if (!verifyCsrfToken(csrfToken)) {
    return NextResponse.json(
      { error: { code: 'CSRF_INVALID' } },
      { status: 403 }
    );
  }
}
```

## 4. Input Validation

### 4.1 Server-Side Validatie

```typescript
import { z } from 'zod';

const CreateQuestionnaireSchema = z.object({
  title: z.string().min(1).max(200),
  status: z.enum(['draft', 'active']),
  item: z.array(QuestionnaireItemSchema)
});

export async function POST(request: Request) {
  const body = await request.json();
  
  const result = CreateQuestionnaireSchema.safeParse(body);
  if (!result.success) {
    return NextResponse.json(
      { error: { code: 'VALIDATION_ERROR', details: result.error.flatten() } },
      { status: 400 }
    );
  }
  
  // Proceed with validated data
}
```

### 4.2 SQL Injection Prevention

**ALTIJD** parameterized queries:

```typescript
// FOUT
const query = `SELECT * FROM users WHERE id = '${userId}'`;

// GOED - via Medplum search (automatically parameterized)
const results = await medplum.search('Patient', { _id: userId });
```

## 5. XSS Prevention

### 5.1 Output Encoding

React escaped automatisch, maar let op:

```typescript
// FOUT - dangerouslySetInnerHTML zonder sanitization
<div dangerouslySetInnerHTML={{ __html: userInput }} />

// GOED - sanitize first
import DOMPurify from 'dompurify';
<div dangerouslySetInnerHTML={{ __html: DOMPurify.sanitize(userInput) }} />
```

## 7. Audit Logging

### 7.1 Log Alle Wijzigingen

```typescript
async function logAuditEvent(event: AuditEvent) {
  await fetch(`${GATEWAY_URL}/audit`, {
    method: 'POST',
    body: JSON.stringify({
      timestamp: new Date().toISOString(),
      user_id: event.userId,
      tenant_id: event.tenantId,
      action: event.action,
      resource_type: event.resourceType,
      resource_id: event.resourceId,
      changes: event.changes
    })
  });
}
```

### 7.2 Verplichte Audit Events

| Event | Wanneer |
|-------|---------|
| `questionnaire.created` | Nieuwe vragenlijst |
| `questionnaire.published` | Status naar active |
| `questionnaire.deleted` | Verwijdering |
| `response.submitted` | Patient response |
| `user.login` | Login poging |
| `user.logout` | Logout |

## 8. Sensitive Data Logging

**NOOIT** loggen:

- Passwords
- API keys
- Patient health data (PHI)
- Session tokens
- Full request bodies met sensitive data

```typescript
// FOUT
console.log('Request:', JSON.stringify(request.body));

// GOED
console.log('Request to:', request.url, 'by user:', auth.user_id);
```

## 9. Session Management

### 9.1 HTTP-Only Cookies

```typescript
cookies().set('session', token, {
  httpOnly: true,
  secure: process.env.NODE_ENV === 'production',
  sameSite: 'strict',
  maxAge: 60 * 60 * 24 // 24 hours
});
```

### 9.2 Session Invalidation

Bij logout of security event:

```typescript
async function invalidateSession(sessionId: string) {
  await fetch(`${GATEWAY_URL}/auth/logout`, {
    method: 'POST',
    headers: { 'X-Session-Id': sessionId }
  });
  
  cookies().delete('session');
}
```
