# Coding Instincts

## 1. Data Storage

### NOOIT localStorage

```typescript
// FOUT - data persistence in localStorage
localStorage.setItem('questionnaires', JSON.stringify(data));

// GOED - via gateway naar database
await gatewayFetch('/api/questionnaires', {
  method: 'POST',
  body: JSON.stringify(data)
});
```

### NOOIT Client-Side State voor Persistence

```typescript
// FOUT - useState voor persistente data
const [questionnaires, setQuestionnaires] = useState<Questionnaire[]>([]);

// GOED - SWR voor server state
const { data: questionnaires } = useSWR('questionnaires', fetcher);
```

## 4. Error Handling

### ALTIJD Try-Catch in API Routes

```typescript
export async function GET(request: Request) {
  try {
    const auth = await verifyGatewayAuth(request);
    const data = await fetchData();
    return NextResponse.json({ data });
  } catch (error) {
    if (error instanceof GatewayAuthError) {
      return NextResponse.json({ error: { code: 'AUTH_REQUIRED' } }, { status: 401 });
    }
    console.error('[HealthTalk] Error:', error);
    return NextResponse.json({ error: { code: 'INTERNAL_ERROR' } }, { status: 500 });
  }
}
```

### NOOIT Swallow Errors

```typescript
// FOUT
try {
  await saveData();
} catch (error) {
  // Silently ignore
}

// GOED
try {
  await saveData();
} catch (error) {
  console.error('[HealthTalk] Save failed:', error);
  throw error; // Of handle appropriately
}
```

## 8. Async/Await

### ALTIJD Async/Await over .then()

```typescript
// FOUT
gatewayFetch('/api/data')
  .then(res => res.json())
  .then(data => setData(data));

// GOED
const response = await gatewayFetch('/api/data');
const data = await response.json();
```

## 9. Naming Conventions

| Type | Convention | Example |
|------|------------|---------|
| Components | PascalCase | `QuestionnaireBuilder` |
| Hooks | camelCase, use* prefix | `useQuestionnaires` |
| Utils | camelCase | `formatDate` |
| Constants | SCREAMING_SNAKE | `MAX_ITEMS` |
| Types | PascalCase | `QuestionnaireResponse` |
| Files (components) | kebab-case | `questionnaire-builder.tsx` |
| Files (pages) | kebab-case or `page.tsx` | `page.tsx` |
