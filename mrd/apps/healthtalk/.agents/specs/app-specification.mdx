# HealthTalk Admin Application Specification

## Overview

HealthTalk is an AI-powered clinical reporting platform for mental healthcare professionals (psychologists, psychiatrists). The platform converts speech-to-text from therapy sessions into structured clinical documentation.

## Target Users

| Role | Description |
|------|-------------|
| **Psychologists** | Primary users - conduct therapy sessions |
| **Psychiatrists** | Medical oversight, medication consultations |
| **Practice Managers** | Organization and user management |
| **Admins** | System-wide administration |

## Core Features

### 1. Gesprekken (Conversations)
- Record therapy sessions (1 hour audio)
- Speech-to-text transcription
- AI-powered clinical report generation
- Template-based documentation

### 2. Cliënten (Clients)
- Patient management
- Demographics (name, birthdate, gender)
- Linked conversations history
- FHIR Patient resource integration

### 3. Sjablonen (Templates)
- Pre-built GGZ documentation templates
- Categories: Intake, Evaluatie, Behandeling, Diagnostiek
- Multi-language support (NL/EN)
- Favorites system
- Template types include:
  - Heteroanamnese
  - Evaluatieverslag
  - CGT Sessie
  - Medicatieconsult
  - Embloombespreking
  - Keukentafelgesprek

### 4. Admin / Beheerpaneel
- Organization management (33+ organizations)
- User management per organization
- Access control (Alleen Eigen Cliënten)
- Practitioner role assignment

### 5. Profiel
- User profile management
- Organization switching
- Language selection (NL/EN)
- Logout functionality

## Technical Requirements

### Authentication
- OAuth via Gateway (auth-test-b2c.healthtalk.ai)
- Role-based access (Practitioner, Admin)
- Organization-scoped data access

### Data Flow
```
UI → API Route → Gateway → Medplum FHIR Server
                        → Supabase (templates, transcripts)
```

### FHIR Resources Used
- Patient (Cliënten)
- Practitioner (Users)
- Organization (Practices)
- Questionnaire (Templates)
- QuestionnaireResponse (Filled templates)
