# Design System

## 1. Principes

- **shadcn/ui only** - Geen custom CSS, geen inline styles
- **Tailwind CSS** - Utility-first styling
- **React Flow** - Voor visuele workflows
- **Brand theming** - Via CSS variables per brand

## 2. Component Library

### 2.1 Basis Componenten (shadcn/ui)

| Component | Gebruik |
|-----------|---------|
| `Button` | Acties, CTAs |
| `Card` | Content containers |
| `Dialog` | Modals |
| `Form` | Formulieren met validatie |
| `Input` | Text inputs |
| `Select` | Dropdowns |
| `Tabs` | Tab navigatie |
| `Table` | Data tabellen |
| `Badge` | Status indicators |

### 2.2 Import Pattern

```typescript
// Correct
import { Button } from '@/components/ui/button';
import { Card, CardHeader, CardContent } from '@/components/ui/card';

// Incorrect - NIET DOEN
import { Button } from 'shadcn';  // Bestaat niet
```

## 5. Layout Patterns

### 5.1 Page Layout

```typescript
export default function Page() {
  return (
    <div className="container mx-auto py-6">
      <div className="flex items-center justify-between mb-6">
        <h1 className="text-2xl font-bold">Page Title</h1>
        <Button>Action</Button>
      </div>
      
      <Card>
        <CardContent className="p-6">
          {/* Content */}
        </CardContent>
      </Card>
    </div>
  );
}
```

### 5.2 Form Layout

```typescript
<Form {...form}>
  <form onSubmit={form.handleSubmit(onSubmit)} className="space-y-6">
    <FormField
      control={form.control}
      name="title"
      render={({ field }) => (
        <FormItem>
          <FormLabel>Title</FormLabel>
          <FormControl>
            <Input {...field} />
          </FormControl>
          <FormMessage />
        </FormItem>
      )}
    />
    
    <Button type="submit">Save</Button>
  </form>
</Form>
```

### 5.3 Grid Layout

## 6. Status Indicators

### 6.2 Score Severity Colors

| Severity | Color | Tailwind |
|----------|-------|----------|
| Minimal | Green | `bg-green-500` |
| Mild | Yellow | `bg-yellow-500` |
| Moderate | Orange | `bg-orange-500` |
| Severe | Red | `bg-red-500` |

```typescript
const severityColors: Record<string, string> = {
  minimal: 'bg-green-500 text-white',
  mild: 'bg-yellow-500 text-black',
  moderate: 'bg-orange-500 text-white',
  severe: 'bg-red-500 text-white'
};

<Badge className={severityColors[severity]}>
  {label}
</Badge>
```

## 7. Accessibility

### 7.1 Regels

- Alle interactieve elementen hebben focus states
- Kleurcontrast minimaal 4.5:1 voor tekst
- Formulieren hebben labels en error messages
- Modals zijn keyboard navigeerbaar

### 7.2 Screen Reader Support

```typescript
// sr-only class voor screen reader only text
<Button>
  <Icon className="h-4 w-4" />
  <span className="sr-only">Delete item</span>
</Button>
```
