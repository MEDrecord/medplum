# Medplum Integration

## 1. Overzicht

HealthTalk gebruikt Medplum als FHIR R4 backend voor:

- Patient resources
- Practitioner resources
- Questionnaire en QuestionnaireResponse
- Observation (voor scores)
- Appointment
- Encounter

## 2. Client Factory

### 2.1 Server-Side Client

```typescript
// lib/medplum.ts
import { MedplumClient } from '@medplum/core';

let serverClient: MedplumClient | null = null;

export function getMedplumClient(): MedplumClient {
  if (!serverClient) {
    serverClient = new MedplumClient({
      baseUrl: process.env.MEDPLUM_BASE_URL,
      clientId: process.env.MEDPLUM_CLIENT_ID,
      clientSecret: process.env.MEDPLUM_CLIENT_SECRET
    });
  }
  return serverClient;
}
```

### 2.2 Auth-Scoped Client

```typescript
export function getMedplumClientFromAuth(auth: GatewayAuth): MedplumClient {
  const client = new MedplumClient({
    baseUrl: process.env.MEDPLUM_BASE_URL,
    accessToken: auth.accessToken
  });
  
  // Set project context for tenant isolation
  client.setActiveProject(auth.tenant_id);
  
  return client;
}
```

## 4. Operations

### 4.1 Search

```typescript
// Search questionnaires
const bundle = await medplum.search('Questionnaire', {
  status: 'active',
  _sort: '-_lastUpdated',
  _count: '50'
});

const questionnaires = bundle.entry?.map(e => e.resource as Questionnaire) || [];
```

### 4.2 Create

```typescript
const created = await medplum.createResource<Questionnaire>({
  resourceType: 'Questionnaire',
  status: 'draft',
  title: 'New Questionnaire'
});
```

### 4.3 Update

```typescript
const updated = await medplum.updateResource<Questionnaire>({
  ...questionnaire,
  status: 'active'
});
```

### 4.4 Delete

```typescript
await medplum.deleteResource('Questionnaire', questionnaire.id);
```

## 5. SDC Operations

### 5.1 $extract

Extract QuestionnaireResponse data naar andere resources:

```typescript
const extracted = await medplum.executeBot(
  'extract-bot',
  {
    resourceType: 'Parameters',
    parameter: [{
      name: 'questionnaire-response',
      resource: questionnaireResponse
    }]
  }
);
```

### 5.2 $populate

Pre-populate een questionnaire met bestaande patient data:

```typescript
const populated = await medplum.post(
  medplum.fhirUrl('Questionnaire', questionnaire.id, '$populate'),
  {
    resourceType: 'Parameters',
    parameter: [{
      name: 'subject',
      valueReference: { reference: `Patient/${patientId}` }
    }]
  }
);
```

## 8. Environment Variables

| Variable | Beschrijving | Server-only |
|----------|--------------|-------------|
| `MEDPLUM_BASE_URL` | Medplum API URL | Yes |
| `MEDPLUM_CLIENT_ID` | OAuth client ID | Yes |
| `MEDPLUM_CLIENT_SECRET` | OAuth client secret | Yes |
| `MEDPLUM_PROJECT_ID` | Default project ID | Yes |

## 9. Belangrijke Regels

1. **NOOIT** directe Medplum calls vanuit client components
2. **ALTIJD** via API routes die gateway auth verifiëren
3. **ALTIJD** tenant-scoped queries via `_project` parameter
4. **NOOIT** Medplum credentials in client-side code
