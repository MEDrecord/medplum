# Template Systeem

## 1. Overzicht

Het template systeem ondersteunt twee typen templates:

| Type | Doel | Tweede Tab |
|------|------|------------|
| **Note Template** | AI rapport generatie uit transcripties | Sections (AI guidelines + output format) |
| **Questionnaire** | Data collectie met optionele scoring | Questions (MedPlum `<QuestionnaireBuilder />`) |

Beide typen delen dezelfde shell (naam, categorieën, taal, draft/publish flow, visibility).

## 2. Template Data Structuur

### 2.1 TemplateDetailResponse

```typescript
interface TemplateDetailResponse {
  id: string;
  owner_id: string;

  created_at: string;
  updated_at: string;
  translations: TemplateTranslationResponse[];
  categories: TemplateCategoryResponse[];
  tags: TemplateTagResponse[];
  sections?: TemplateSectionResponse[];     // Voor note-templates

  is_favorited: boolean;

```

### 2.2 Template Vertalingen

```typescript
interface TemplateTranslationResponse {

```

### 2.3 Sectie Structuur (Note Templates)

```typescript
interface TemplateSectionResponse {
  id: string;
  section_id: string;
  output_format: 'free_text' | 'bullet_points' | 'structured_fields';
  display_order: number;
  translations: TemplateSectionTranslation[];

interface TemplateSectionTranslation {
  language_code: string;
  name: string;           // Sectie naam (bijv. "Anamnese")
```

## 4. Rapport Generatie Flow

### 4.1 Regenerate Summary

```typescript
const { regenerateSummary, isRegenerating } = useRegenerateSummary();

const customSummaries = await regenerateSummary({
  appointmentId: 'apt-123',
  language: 'NL',
  conversationTemplateId: 'template-uuid',
  additionalPrompt: 'Extra instructie voor AI'
});
```

### 4.2 Backend Flow

1. **POST regenerate** - Start async job, krijgt `regenerationId`
2. **Poll status** - Elke 4s check tot status !== `PROCESSING`
3. **Fetch summary** - Na `COMPLETED`, haal volledige data op
4. **Assign template** - Koppel template aan appointment

### 4.3 AI Prompt Constructie

De AI prompt wordt opgebouwd uit:

1. **Template-level `ai_guidance`** - Algemene instructies
2. **Per-sectie `ai_guidance`** - Specifieke instructies per sectie
3. **`additionalPrompt`** - User-defined extra instructies
4. **`language`** - Taal voor output

```typescript
  }>>;  // templateId -> sectionId -> data
  customSummariesUpdatedAt?: Record<string, number>;
  reportRegenerationStatus?: 'PROCESSING' | 'COMPLETED' | 'FAILED';

```

### 5.2 Selectie van Laatste Template

```typescript
// lib/utils/summary-utils.ts
function getLatestTemplateId(
  customSummaries: Record<string, any>,
  customSummariesUpdatedAt: Record<string, number>
): string | undefined {
  return Object.entries(customSummariesUpdatedAt || {})
    .sort(([, a], [, b]) => b - a)[0]?.[0];
}
```

### 8.3 Template Taal Selectie

```typescript
function getTranslation(
  translations: TemplateTranslationResponse[],
  language: string
): TemplateTranslationResponse | undefined {
  return translations.find(t => t.language_code === language) 
    || translations[0];
}
```
