# Template Systeem

## 1. Overzicht

Het template systeem ondersteunt AI-gestuurde rapportgeneratie voor klinische sessies. Templates definiëren de structuur en AI prompts voor het genereren van gestructureerde rapporten uit gesprekstranscripties.

### 1.1 Template Types

Het systeem ondersteunt twee typen templates:

| Type | Doel | Tweede Tab |
|------|------|------------|
| **Note Template** | AI rapport generatie uit transcripties | Sections (AI guidelines + output format) |
| **Questionnaire** | Data collectie met optionele scoring | Questions (MedPlum `<QuestionnaireBuilder />`) |

Beide typen delen dezelfde shell (naam, categorieën, taal, draft/publish flow, visibility).

### 1.2 Gateway Services

De applicatie communiceert met drie gateway services:

| Environment Variable | Service | Doel |
|-----|-----|-----|
| `NEXT_PUBLIC_TEMPLATE_SERVICE_GATEWAY_URL` | Template Service | Templates CRUD, secties, talen, tags, categorieën |
| `NEXT_PUBLIC_CONSULTATION_SERVICE_GATEWAY_URL` | Consultation Service | Appointments, rapport regeneratie, transcripties |
| `NEXT_PUBLIC_GATEWAY_BASE_URL` | Auth Gateway | Authenticatie, sessie management |

**Voorbeeld URLs:**

```plaintext
NEXT_PUBLIC_TEMPLATE_SERVICE_GATEWAY_URL=https://auth-test-b2c.healthtalk.ai
NEXT_PUBLIC_CONSULTATION_SERVICE_GATEWAY_URL=https://consultation.healthtalk.ai
NEXT_PUBLIC_GATEWAY_BASE_URL=https://auth-test-b2c.healthtalk.ai
```

## 4. Rapport Generatie Flow

### 4.1 Regenerate Summary

```typescript
const { regenerateSummary, isRegenerating } = useRegenerateSummary();

const customSummaries = await regenerateSummary({
  appointmentId: 'apt-123',
  language: 'NL',
  conversationTemplateId: 'template-uuid',
  additionalPrompt: 'Extra instructie voor AI'
});
```

### 4.2 Backend Flow

1. **POST regenerate** - Start async job, krijgt `regenerationId`
2. **Poll status** - Elke 4s check tot status !== `PROCESSING`
3. **Fetch summary** - Na `COMPLETED`, haal volledige data op
4. **Assign template** - Koppel template aan appointment

### 4.3 AI Prompt Constructie

De AI prompt wordt opgebouwd uit:

1. **Template-level `ai_guidance`** - Algemene instructies
2. **Per-sectie `ai_guidance`** - Specifieke instructies per sectie
3. **`additionalPrompt`** - User-defined extra instructies
4. **`language`** - Taal voor output

### 9.2 useTemplatesList Implementatie

```typescript
export function useTemplatesList(options?: TemplatesListOptions) {
  const { language } = useTranslation();
  
  const { data, error, isLoading, mutate } = useSWR(
    ['templates', options, language],
    async () => {
      const params = new URLSearchParams({
        page: String(options?.page || 1),
        limit: String(options?.limit || 20),
        language
      });
      
      if (options?.search) params.set('search', options.search);
      if (options?.visibility) params.set('visibility', options.visibility);
      if (options?.type) params.set('type', options.type);
      if (options?.sort_by) params.set('sort_by', options.sort_by);
      if (options?.sort_order) params.set('sort_order', options.sort_order);
      
      const response = await gatewayFetch(
        `${TEMPLATE_SERVICE_URL}/api/v1/templates?${params}`
      );
      
      if (!response.ok) throw new Error('Failed to fetch templates');
      return response.json();
    }
  );
  
  return {
    templates: data?.data?.data || [],
    pagination: data?.data?.pagination,
    isLoading,
    error,
    hasMore: data?.data?.pagination?.has_more,
    loadMore: () => mutate(),
    refresh: mutate
  };
}
```

### 9.3 useTemplateById Implementatie

```typescript
export function useTemplateById(id: string | undefined) {
  const { language } = useTranslation();
  
  const { data, error, isLoading } = useSWR(
    id ? ['template', id, language] : null,
    async () => {
      const response = await gatewayFetch(
        `${TEMPLATE_SERVICE_URL}/api/v1/templates/${id}?language=${language}`
      );
      if (!response.ok) throw new Error('Failed to fetch template');
      return response.json();
    }
  );
  
  return {
    template: data?.data as TemplateDetailResponse | undefined,
    isLoading,
    error,
    language
  };
}
```

### 9.4 useRegenerateSummary Implementatie

```typescript
export function useRegenerateSummary() {
  const [isRegenerating, setIsRegenerating] = useState(false);
  
  const regenerateSummary = useCallback(async (params: {
    appointmentId: string;
    language: string;
    conversationTemplateId: string;
    additionalPrompt?: string;
  }) => {
    setIsRegenerating(true);
    
    try {
      // 1. Start regeneration
      const startResponse = await gatewayFetch(
        `${CONSULTATION_SERVICE_URL}/api/callreport/regenerate`,
        {
          method: 'POST',
          headers: { 'Content-Type': 'application/json' },
          body: JSON.stringify(params)
        }
      );
      
      if (!startResponse.ok) throw new Error('Failed to start regeneration');
      const { regenerationId } = await startResponse.json();
      
      // 2. Poll for completion (elke 4s, max 6 min)
      const maxAttempts = 90;
      for (let i = 0; i < maxAttempts; i++) {
        await new Promise(resolve => setTimeout(resolve, 4000));
        
        const statusResponse = await gatewayFetch(
          `${CONSULTATION_SERVICE_URL}/api/callreport/summary?appointmentId=${params.appointmentId}`
        );
        
        const data = await statusResponse.json();
        
        if (data.reportRegenerationStatus === 'COMPLETED') {
          // 3. Assign template to appointment
          await gatewayFetch(
            `${CONSULTATION_SERVICE_URL}/api/appointment/assign-conversation-template`,
            {
              method: 'PATCH',
              headers: { 'Content-Type': 'application/json' },
              body: JSON.stringify({
                appointmentId: params.appointmentId,
                conversationTemplateId: params.conversationTemplateId
              })
            }
          );
          
          return data.customSummaries;
        }
        
        if (data.reportRegenerationStatus === 'FAILED') {
          throw new Error('Report generation failed');
        }
      }
      
      throw new Error('Timeout waiting for report generation');
      
    } finally {
      setIsRegenerating(false);
    }
  }, []);
  
  return { regenerateSummary, isRegenerating };
}
```
